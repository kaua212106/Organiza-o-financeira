✅ Modo seguro: informe somente endereços públicos. Nunca cole seed phrase, chave privada, senha bancária ou API Secret aqui.

👛 Carteira pública

Para BlueWallet, você pode colar a zpub. Ela permite acompanhar todos os endereços derivados da carteira, mas não permite movimentar seus bitcoins. Trate-a como informação privada de acompanhamento.

🏦 Bancos e exchanges

Por segurança, login bancário e API Secret de corretora não são aceitos neste HTML. A conexão automática deve usar OAuth/Open Finance ou um servidor intermediário seguro. Esta versão não armazena essas credenciais.
🏦 Open FinancePreparado para conexão por redirecionamento OAuth em uma versão com backend. A autenticação deve acontecer no próprio banco/provedor.
₿ ExchangesPreparado para API somente leitura via servidor. Nunca habilite negociação ou saque para um app de acompanhamento.

A CoinStats aceita xpub, ypub e zpub e agrega os endereços derivados. A chave da API é apenas do serviço de consulta; nunca use seed ou chave privada. Consultas HD podem consumir mais créditos da API.

Essas chaves são de consulta de dados públicos e serão excluídas dos backups.
